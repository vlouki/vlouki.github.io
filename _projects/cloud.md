## Overview

An academic project inspired by the concept of the famous movie **"Inception"**, but instead of a dream within a dream, I created a cloud within a cloud!

The project focused on deploying, configuring, and managing an OpenStack environment using **DevStack** on a **Google Cloud virtual machine (VM)**. This approach enabled the creation of a fully functional cloud management environment within an existing Infrastructure as a Service (IaaS) platform, demonstrating the concept of nested cloud infrastructure.

## Key Activities

- Installed and configured OpenStack using DevStack.
- Managed projects, users, and resource quotas.
- Configured virtual networks, subnets, routers, and security groups.
- Provisioned virtual machines and managed floating IP addresses.
- Explored cloud administration through the Horizon dashboard and command-line tools.

## Technologies Used

- OpenStack
- DevStack
- Google Cloud Platform
- Linux
- Networking and virtualization

## Learning Outcomes

The project provided practical experience with infrastructure management, virtual networking, cloud resource provisioning and troubleshooting.
