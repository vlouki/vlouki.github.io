## Overview

A team-based academic project combining web application development with DevOps practices and deployment automation. The application supports a role-based pet adoption workflow, while its infrastructure demonstrates automated deployment and continuous integration.

## Application Development

- Developed backend functionality using Java and Spring Boot.
- Implemented authentication and authorization with Spring Security.
- Built server-rendered interfaces using Thymeleaf.
- Used MariaDB for data persistence.

## DevOps & Deployment

- Containerized application services using Docker.
- Automated infrastructure configuration and deployment using Ansible.
- Configured Jenkins pipelines for testing, image builds, and deployment.
- Deployed application components across Azure virtual machines.
- Integrated Nginx, MinIO, and MailHog.
